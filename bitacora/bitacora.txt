Proyecto: Plataforma de Noticias Apícolas Automatizada

Resumen
El objetivo del proyecto es crear un portal web centralizado para la industria apícola que recopile, filtre y presente noticias relevantes de manera automática. El sistema utiliza Inteligencia Artificial para clasificar contenido técnico y de mercado, asignando imágenes temáticas para mejorar la experiencia visual. Se incluye una interfaz de usuario interactiva con gestión de perfiles.

Stack Tecnológico (Tecnologías utilizadas)
Frontend: Next.js 14 (React) + Tailwind CSS (Estilos).
Backend: Python + Django Rest Framework (API).
Base de Datos: SQLite (Entorno local).
Automatización & AI: n8n (Workflow de Agentes IA).
Fuentes de Datos: RSS Feeds + Unsplash API (Imágenes).

Fase 2: Desarrollo de la Lógica de Negocio (Backend)
A. Modelado de Datos
Se diseñó la estructura de la base de datos para soportar noticias generadas por IA.

Cambio Crítico: Originalmente el campo de imagen esperaba un archivo (ImageField). Se modificó a URLField para permitir que la IA inyecte enlaces directos de bancos de imágenes sin necesidad de descarga física.

Código Clave (models.py):

Python

class Article(models.Model):
    title = models.CharField(max_length=200)
    # Cambio estratégico para integración con n8n:
    image = models.URLField(max_length=500, blank=True, null=True) 
    category = models.ForeignKey(Category, related_name='articles', on_delete=models.CASCADE)
    # ... otros campos (content, excerpt, slug, etc.)
Migraciones:

Bash

python manage.py makemigrations
python manage.py migrate
Fase 3: Automatización e Inteligencia Artificial (n8n)
Se implementó un "Agente Periodista" en n8n que lee noticias RSS y las procesa.

A. Lógica del Prompt (Cerebro de la IA)
El prompt fue diseñado utilizando documentos técnicos de la industria para asegurar que la IA distinga entre temas de Producción, Sanidad, Mercado y Tecnología.

Características del Prompt:

Filtro Técnico: Se integraron palabras clave del documento original (ej: Varroa, Ecofisiología, Polinización) para clasificar las noticias con precisión.

Sistema Anti-Repetición de Imágenes: Se configuró una galería cerrada de 9 imágenes de alta calidad (divididas en grupos: Flores, Apiarios, Apicultores, Productos) para evitar que todas las noticias tengan la misma foto.

Formato de Salida: JSON estructurado compatible con la API de Django.

B. Flujo de Trabajo (Workflow)

Trigger: Lectura de RSS cada X tiempo.

AI Agent: Procesa texto, asigna categoría geográfica y selecciona imagen.

HTTP Request: Envía los datos limpios a http://127.0.0.1:8000/api/articles/.

Fase 5: Módulo de Usuario y Autenticación (Frontend)
A. Simulación de Autenticación

Creación de vista de Login (/login) con diseño acoplado al branding.

Implementación temporal de guardado de sesión en localStorage para pruebas de navegación.

B. Panel de Perfil de Usuario (/profile)

Creación de un Dashboard personal con generación dinámica de avatar basado en el nombre de usuario.

Implementación de formulario de datos de contacto (Nombre, Apellido, RUT, Correo, Teléfono, Dirección).

Lógica de edición bidireccional y guardado en memoria local.

Regla de Negocio UI: Los campos "Nombre" y "Apellido", una vez completados y guardados por primera vez, pasan a un estado de bloqueo visual (Solo lectura / 🔒 Fijo), permitiendo edición continua solo en los datos de contacto y RUT.

Estado Actual 
Estado: El sistema extrae noticias mediante IA de forma autónoma y las renderiza en una interfaz web robusta. El frontend cuenta con un sistema simulado de usuarios, panel de perfil interactivo y lógica de lectura/escritura en caché del navegador.
